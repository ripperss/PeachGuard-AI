## О проекте

Выращивание персика — сложная задача. Курчавость листьев, клястероспориоз (дырчатая пятнистость), монилиоз (плодовая гниль) и мучнистая роса могут уничтожить урожай за неделю.
**PeachGuard AI** использует нейронные сети, чтобы по одному снимку с точностью >90% определить болезнь и дать рекомендации по обработке.

## Возможности

- **интерфейс** — удобно на любом телефоне.
-**Определение 3+ классов болезней**:
  - Курчавость листьев (*Taphrina deformans*)
  - Дырчатая пятнистость (Клястероспориоз)
  - Монилиоз (Плодовая гниль)
  - Здоровое растение
  -  **Мгновенный ответ** (обработка < 2 секунд).
  -  **Советы по лечению** — названия препаратов (фунгициды) и агротехнические меры.

## Как это работает

1. Пользователь отправляет фото.
2. Изображение сжимается до 224x224 или 416x416.
3. Предобученная модель выполняет инференс.
4. Бот возвращает:
   - *Название болезни*
   - *Вероятность*
   - *План лечения*
